# Boda Games 🎮

منصة ألعاب جماعية أونلاين بواجهة عربية RTL وتصميم نيون ثلاثي الأبعاد (CSS 3D).
المطوّر: **Boda — بوده المكسيكي**

## ما الذي يعمل في هذه النسخة (MVP v0.1)

| الميزة | الحالة |
|---|---|
| دخول كضيف باسم مستعار | ✅ يعمل |
| إنشاء غرفة عامة أو خاصة + كود فريد + حد أقصى للاعبين | ✅ يعمل |
| رابط دعوة قابل للنسخ + مشاركة واتساب | ✅ يعمل |
| نظام الجاهزية + بدء المباراة + طرد اللاعبين (للمالك فقط، والتحقق على الخادم) | ✅ يعمل |
| لعبة XO أونلاين + نقاط + إعادة مباراة (تبديل من يبدأ) | ✅ يعمل |
| شات كتابي فوري + رموز تعبيرية | ✅ يعمل |
| صوت جماعي WebRTC (كتم، مستوى الصوت، مغادرة، حالة الميكروفون) | ✅ مكتوب (Mesh) — يحتاج اختبارك على جهازين |
| إعادة الاتصال تلقائيًا بعد انقطاع الإنترنت (مهلة 45 ثانية) | ✅ مكتوب |
| الغرف العامة وقائمة اللاعبين | ✅ يعمل |
| تسجيل حساب + قاعدة بيانات (Supabase) | ❌ غير منفّذ بعد |
| قائمة الأصدقاء | ❌ غير منفّذة بعد |
| الألعاب الـ11 الأخرى (لودو، داما، كوتشينة…) | ❌ غير منفّذة بعد، ولا تظهر كأزرار |

> الكود تم فحص صياغته فقط، ولم أتمكن من تشغيله واختباره بسبب غياب الشبكة في بيئة الإنشاء. اختبره بالخطوات أدناه قبل النشر.

## هيكل المشروع

```
boda-games/
├─ server.js        # Express + Socket.IO (الغرف، XO، الشات، إشارات WebRTC)
├─ package.json
├─ .env.example     # إعدادات مثال بلا أسرار

│  ├─ index.html

│  ├─ app.js
```

## التشغيل محليًا

1. ثبّت Node.js 20 أو أحدث.
2. داخل مجلد المشروع:
```bash
npm install
cp .env.example .env
npm run dev
```
3. افتح `http://localhost:3000`.

## اختبار الموقع من هاتفين

**مهم:** المتصفحات على الهاتف لا تسمح بالميكروفون إلا عبر **HTTPS**، لذلك عنوان مثل `http://192.168.1.5:3000` لن يشغّل الصوت. لديك خياران:

- **الأسهل:** انشر على Render (الأسفل) ثم افتح الرابط من الهاتفين.
- **محليًا:** شغّل نفق HTTPS مثل `cloudflared tunnel --url http://localhost:3000` أو `ngrok http 3000`، وافتح الرابط الناتج من الهاتفين.

سيناريو الاختبار:
1. الهاتف 1: اكتب اسمًا ← إنشاء غرفة ← انسخ الرابط أو الكود.
2. الهاتف 2: افتح الرابط (أو اكتب الكود) ← اكتب اسمًا ← انضمام.
3. الهاتف 2: اضغط «جاهز». الهاتف 1: اضغط «ابدأ المباراة».
4. العبا XO بالتناوب وتأكد من تزامن اللوحة والنقاط، ثم «إعادة المباراة» من الطرفين.
5. أرسلا رسائل في الشات أثناء اللعب.
6. في الهاتفين: «انضمام للمكالمة» ← اسمح بالميكروفون ← تأكد من سماع الصوت، جرّب الكتم ومستوى الصوت.
7. أغلق الواي فاي في أحد الهاتفين لثوانٍ ثم أعده: يجب أن يعود للغرفة تلقائيًا (الصوت يحتاج إعادة انضمام يدويًا).

## النشر (الأسهل: كل شيء على Render)

GitHub Pages **لا يشغّل Node.js**؛ لذلك الخادم يحتاج خدمة مثل Render.

1. أنشئ حسابًا على render.com واربطه بحساب GitHub.
2. **New → Web Service** واختر المستودع (أو **Blueprint** ليقرأ `render.yaml`).
3. Build: `npm install` — Start: `npm start` — Health check: `/health`.
4. ضع `CORS_ORIGINS` (اتركه `*` للتجربة، ثم حدّده برابط موقعك).
5. افتح رابط `https://....onrender.com` فتجد الموقع كاملًا (الخادم يقدّم الواجهة أيضًا).

### خيار: الواجهة على GitHub Pages والخادم على Render

1. انشر الخادم على Render كما فوق.
2. عدّل `public/config.js`:
```js
window.BODA_CONFIG = { BACKEND_URL: 'https://your-app.onrender.com' };
```
3. اضبط `CORS_ORIGINS` على Render إلى `https://USERNAME.github.io`.
4. في GitHub: Settings → Pages → اختر الفرع `main` والمجلد `/public` إن توفر، أو انسخ محتوى `public` إلى فرع `gh-pages`.

## حدود الاستخدام المجاني (تحقق من الشروط الحالية)

- **Render المجاني:** ينام الخادم بعد فترة خمول (أول زيارة قد تتأخر نحو دقيقة)، وتُفقد الغرف عند إعادة التشغيل لأنها في الذاكرة. مناسب للتجربة فقط.
- **STUN:** المستخدم هنا خوادم Google العامة المجانية، وتكفي غالبًا لكنها لا تضمن الاتصال عبر كل الشبكات.
- **TURN:** بعض الشبكات (شبكات الجوال خصوصًا) تتطلب TURN ليعمل الصوت. لا يوجد TURN مجاني غير محدود؛ سجّل في خدمة (مثل Metered أو Cloudflare) أو شغّل coturn على خادمك، ثم ضع القيم في `TURN_URL` و`TURN_USERNAME` و`TURN_CREDENTIAL` على Render. دون TURN قد يفشل الصوت لبعض اللاعبين.
- **الصوت Mesh:** كل لاعب يتصل بالآخرين مباشرة، وهذا مناسب لنحو 4–6 أشخاص كحد أقصى.

## أمان

- لا توجد مفاتيح سرية في الواجهة؛ بيانات TURN تأتي من متغيرات بيئة الخادم عبر `/api/ice`.
- صلاحيات البدء والطرد والحركات تُتحقق في الخادم. للغرف الخاصة لا تظهر في القائمة ويلزم الكود.
- كل لاعب له رمز سري (token) في المتصفح لإعادة الدخول، ومعرّف عام منفصل يراه الآخرون.
